EQUITAS - Landing Page para Demo Day

CONTENIDO
- index.html: sitio web responsivo (HTML + CSS sin framework)
- assets/favicon.svg: ícono de pestaña
- assets/equitas-logo.png: logo original proporcionado por el equipo, conservado como recurso

PARA VER EL SITIO
1. Abrí index.html en Chrome, Edge u otro navegador.

PARA PUBLICARLO GRATIS EN NETLIFY
1. Descomprimí el ZIP.
2. Ingresá a https://app.netlify.com/drop
3. Arrastrá la carpeta equitas-landing (la carpeta que contiene index.html).
4. Netlify te entrega una URL pública.
5. Generá el código QR usando esa URL y colocá el QR en el póster.

IMPORTANTE
- La URL definitiva debe existir antes de crear e imprimir el QR.
- Para usar un dominio propio, configuralo en tu plataforma de hosting.
- No se agregaron formularios ni links de contacto porque no se proporcionaron datos públicos del equipo.
- Los segmentos ilustrados son ejemplos conceptuales y no métricas reales.
